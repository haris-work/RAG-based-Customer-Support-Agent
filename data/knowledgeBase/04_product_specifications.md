# Product Specifications

> This is the static technical reference for the 16 products in `03_product_catalog.md`. Specifications are fictional but intended to be technically plausible. Actual unit/marketplace revisions should be verified against the purchased SKU and its package label.

## Reading specifications

- “Up to” values describe supported maxima under stated conditions, not guaranteed real-world performance.
- Wireless range, battery life, charging rate and network throughput depend on host devices, environment, settings and usage.
- Do not infer unlisted features. If a specification is not stated here, tell the customer that the knowledge base does not confirm it.
